# 蝴蝶人 · Butterfly Human

Independent meme project website: https://hudieren.com

Responsive, bilingual Chinese/English static site. No build dependencies, wallets or account collection. Deploy the repository root to Vercel with framework preset Other.

## Local preview

Run `python3 -m http.server 3000` in this directory.

## Launch updates

The project is in preparation. No contract, token rules, launch time or verified social channels have been supplied. Update both `data-zh` and `data-en` fields in index.html when confirmed. The flap.sh button points to the platform homepage and is explicitly labeled accordingly. Do not substitute a buy button until a verified token URL exists.

## Files

- index.html: content and bilingual strings
- style.css: responsive theme and reduced-motion support
- app.js: language preference and clipboard sharing
- assets/: original mascot, avatar, poster, social preview and SVG mark

Project art is provided for Butterfly Human community creative use. Do not imply platform endorsement or guaranteed returns.
